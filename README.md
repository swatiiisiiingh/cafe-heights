# 🍝 Cafe Heights

**Authentic Italian cuisine, crafted with amore.**

Cafe Heights is a personal practice project built with [Next.js](https://nextjs.org) — an exploration of how to design and build a restaurant/cafe website. It covers a full front-of-house experience: a themed landing page, a menu, reservations, events, and more, styled around an Italian trattoria concept.

🔗 **Live demo:** [cafe-heights.vercel.app](https://cafe-heights.vercel.app/)

---

## ✨ Features

- **Home** — hero landing page with the restaurant's story and highlights
- **Menu** — browse dishes by category, priced and ready to order
- **Reservations** — book a table for a date and party size
- **Events** — upcoming happenings at the cafe
- **About** — the Cafe Heights story, since 1987
- **Contact** — location, phone, and email
- **Cart & Sign In** — order flow and user accounts

## 🚀 Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.
